4. Implementación del SDK Multiplataforma

Fragmentos de código de producción probados y optimizados para seguridad de hilos, concurrencia asíncrona y transmisión eficiente de atributos.

Application.kt (Android Kotlin Asíncrono) Kotlin 2.2+ • Braze Android SDK 36.0.0 
package com.superapp.analytics

import android.app.Application
import com.braze.Braze
import com.braze.configuration.BrazeConfig
import com.braze.support.BrazeLogger

class SuperAppApplication : Application() {
    override fun onCreate() {
        super.onCreate()

        // 1. Configuración programática del SDK de Braze
        val brazeConfig = BrazeConfig.Builder()
            .setApiKey("a1b2c3d4-e5f6-7a8b-9c0d-1e2f3a4b5c6d")
            .setCustomEndpoint("https://sdk.iad-01.braze.com")
            .setHandlePushDeepLinksAutomatically(true)
            .setIsSessionTimeoutInSeconds(10) // Evita fragmentación de sesiones
            .setSdkAuthenticationEnabled(true) // Habilita SDK Auth JWT
            .build()

        // 2. Inicialización estática segura
        Braze.configure(this, brazeConfig)
    }

    /**
     * Identificación asíncrona de usuario para evitar cuellos de botella (ANR)
     */
    fun syncUserProfileAsync(userId: String, jwtToken: String, saldoActual: Double, fechaVencimiento: String) {
        // Asignación de firma JWT de seguridad
        Braze.getInstance(this).setSdkAuthenticationSignature(jwtToken)

        // Asignación de ID externo
        Braze.getInstance(this).changeUser(userId)

        // Mutación de atributos en devolución de llamada asíncrona
        Braze.getInstance(this).getCurrentUser { user ->
            user?.apply {
                setCustomUserAttribute("saldo_actual", saldoActual)
                setCustomUserAttribute("fecha_vencimiento_recibo", fechaVencimiento)
                setCustomUserAttribute("segmento_color", "PREPAGO_GOLD")
            }
        }
    }
}
AppDelegate.swift (iOS Swift SPM) iOS 12.0+ • BrazeKit & BrazeUI 
import UIKit
import BrazeKit
import BrazeUI

@main
class AppDelegate: UIResponder, UIApplicationDelegate {
    
    // Instancia estática del SDK
    static var braze: Braze?

    func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        
        // 1. Configuración Inmutable
        var configuration = Braze.Configuration(
            apiKey: "f8e7d6c5-b4a3-2f1e-0d9c-8b7a6f5e4d3c",
            endpoint: "https://sdk.iad-01.braze.com"
        )
        configuration.api.sdkAuthentication = true
        
        // 2. Instanciación
        let brazeInstance = Braze(configuration: configuration)
        AppDelegate.braze = brazeInstance
        
        return true
    }

    /// Autenticación concurrente moderna con Swift Concurrency (async/await)
    @MainActor
    func authenticateUser(userId: String, jwtToken: String, saldo: Double) async {
        guard let braze = AppDelegate.braze else { return }
        
        // Asignación de firma
        braze.set(sdkAuthenticationSignature: jwtToken)
        
        // Cambio de usuario seguro
        braze.changeUser(userId: userId)
        
        // Mutación de atributos usando el calendario gregoriano nativo
        braze.user.set(customAttribute: "saldo_actual", value: saldo)
        braze.user.set(customAttribute: "fecha_vencimiento_recibo", value: "2026-10-15")
    }
}
brazeService.ts (Web TypeScript / NPM) TypeScript 5.0+ • @braze/web-sdk 
import * as braze from "@braze/web-sdk";

export class BrazeWebService {
  
  public static initBraze(): void {
    braze.initialize("a1b2c3d4-e5f6-7a8b-9c0d-1e2f3a4b5c6d", {
      baseUrl: "https://sdk.iad-01.braze.com",
      enableLogging: false,
      enableSdkAuthentication: true,
      sessionTimeoutInSeconds: 30,
      manageServiceWorkerAutomatically: true
    });

    braze.openSession();
  }

  public static async loginUser(userId: String, jwtToken: string): Promise {
    // Aplicar token cryptographic JWT
    braze.setSdkAuthenticationSignature(jwtToken);
    
    // Cambiar identificador
    braze.changeUser(userId);

    // Actualizar atributos de perfil
    const user = braze.getUser();
    if (user) {
      user.setCustomUserAttribute("segmento_color", "POSTPAGO_PLATINUM");
      user.setCustomUserAttribute("saldo_actual", 45.50);
    }
  }

  public static logPurchaseEvent(orderId: string, amount: number, currency: string): void {
    braze.logPurchase(orderId, amount, currency, 1, {
      checkout_type: "ONE_CLICK_UPSELL",
      source: "WEB_SUPER_APP"
    });
  }
}
Protección y Eficiencia de Datos

5. Ciberseguridad (SDK Auth JWT) & Ingestión en Nube (CDI)

Protección estricta contra inyección de eventos por actores maliciosos y optimización de costos computacionales mediante acceso "Zero-Copy".

Autenticación del SDK (SDK Auth JWT)

En aplicaciones con más de 20 millones de descargas, los atacantes pueden interceptar las peticiones HTTP e inyectar atributos ficticios para agotar los contratos de Data Points. Habilitar la Autenticación del SDK exige que cada llamada lleve una firma criptográfica JWT firmada por el backend del cliente.

// Cabecera JWT generada por Backend:

{ "alg": "RS256", "typ": "JWT", "kid": "braze-key-01" }

// Payload del Token:

{ "sub": "USER_ID_20MM_9918", "exp": 1767225600 }

Cloud Data Ingestion (CDI) Zero-Copy

En lugar de saturar las API REST invocando millones de llamadas cuando los datos de facturación cambian, CDI consulta directamente tablas de Snowflake o BigQuery. Utiliza la columna del servidor UPDATED_AT para extraer solo registros modificados.

-- Consulta Delta Automática de Braze CDI:

SELECT user_id, saldo_actual, fecha_vencimiento

FROM BRAZE_INGESTION_USERS

WHERE UPDATED_AT > :last_sync_timestamp
